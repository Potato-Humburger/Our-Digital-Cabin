## 📬 Asynchronous Communication & Journaling

- Use **Issues** as a mailbox for:
  - Daily Thoughts
  - Virtual Letters
  - Future Date Ideas
- Recommended labels:
  - `heart-to-heart`
  - `memories`
  - `bucket-list`

See issue template:
- [Daily Messaging Template](./.github/ISSUE_TEMPLATE/daily-message.yml)

Memory space:
- [Memory Bank Overview](./memory-bank/README.md)
