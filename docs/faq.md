# ❓ 常见问题解答

## 💬 关于这个仓库

### Q: 这个仓库是用来做什么的？
**A:** 这是一个私密的数字空间，我们作为情侣可以在这里分享回忆、计划、梦想和日常想法。这是爱的数字见证。

### Q: 这真的是私密的吗？
**A:** 是的！仓库设置为**私密**，这意味着只有你们两个可以看到它。只有被明确授予访问权限的人才能看到内容。

### Q: 为什么使用 GitHub？
**A:** GitHub 提供了一个免费、安全且版本化的平台来存储我们的回忆和计划。它就像一个数字时间胶囊，记录我们的旅程。

---

## 📝 使用 Issues 和 Discussions

### Q: Issue 和 Discussion 有什么区别？
**A:**
- **Issues** - 用于特定的记录（每日想法、情书、约会计划、回忆）
- **Discussions** - 用于对话和讨论（电影评论、旅行规划、一般聊天）

### Q: 我如何创建一条回忆？
**A:** 
1. 前往 Issues
2. 点击"新建 Issue"
3. 选择"📸 回忆"模板
4. 填写信息
5. 提交！

### Q: 可以删除 Issue 吗？
**A:** 是的，您可以关闭或删除 Issues。但建议保存它们作为我们故事的一部分。

### Q: Issue 中的标签意味着什么？
**A:** 标签帮助组织记录。例如，`💌-情书` 标记所有情书，`🎯-约会` 标记约会计划。

## 💾 数据管理

### Q: 我应该在哪里添加重要日期？
**A:** 将生日、纪念日和特殊日期添加到 `dates/anniversaries.json`。这样系统就可以自动提醒你。

### Q: 如何更新我们的关系时间表？
**A:** 编辑 `data/metrics.json` 添加你们的开始日期和重要里程碑。

### Q: 什么是 status.json？
**A:** `status.json` 让你更新当前心情、位置和日常亮点。这样另一方随时都知道你的状态。

### Q: 我可以添加自己的 JSON 文件吗？
**A:** 当然！如果你需要追踪特定的东西，随时创建新的 JSON 文件。

## 🎬 项目和清单

### Q: 如何使用观影清单？
**A:** 编辑 `projects/watchlist/movies.json` 添加你们想看的电影和节目。可以添加评分、观看日期等。

### Q: 我如何追踪我们想去的地方？
**A:** 使用 `dates/future-plans.md` 的旅行梦想部分，或创建一个新的 Issue 与标签 `✈️-旅行`。

### Q: 我们可以有预算追踪器吗？
**A:** 可以！创建 `projects/budget-tracker/` 并添加一个 JSON 文件来追踪共享支出。

## 🤖 自动化和工作流

### Q: 什么是 GitHub Actions 工作流？
**A:** 工作流是自动的任务。目前用于同步网页每日亮点、同步悄悄话记录，以及发布 GitHub Pages 网页。

### Q: 我如何启用工作流？
**A:** 
1. 前往 Settings → Actions → General
2. 确保允许所有操作
3. 工作流将自动运行

### Q: 我可以禁用工作流吗？
**A:** 是的。在 `.github/workflows/` 中，你可以删除或注释掉任何工作流文件。

### Q: 工作流时间不对吗？
**A:** 工作流使用 UTC 时间。你可以编辑 `.yml` 文件来改变时间和时区。

## 📁 文件和文件夹

### Q: memories 文件夹是怎样组织的？
**A:** 按年份和月份组织：
```
memories/
├── 2024/
│   ├── 01-january/
│   ├── 02-february/
│   └── ...
└── milestones.json
```

### Q: 我应该在哪里放照片？
**A:** 照片可以上传到相应的 `memories/` 文件夹。GitHub 允许直接在 Issues 中上传。

### Q: .gitignore 做什么？
**A:** `.gitignore` 防止某些文件被上传。它保护隐私（如隐私密钥、敏感文件）。

## 🔒 隐私和安全

### Q: 我的数据安全吗？
**A:** 是的。仓库是私密的，只有你们两个可以访问。GitHub 使用加密存储。

### Q: 我应该在这里存储密码吗？
**A:** **不，绝对不行。** 密码和敏感数据应该存储在 `.env` 文件中，这个文件在 `.gitignore` 中列出。

### Q: 我可以删除旧的记忆吗？
**A:** 您可以，但建议保存它们以便纪念。GitHub 保持完整的历史记录。

### Q: 其他人可以看到我的私密仓库吗？
**A:** 不能。只有那些被明确邀请并拥有访问权限的人才能看到。

## 💻 技术问题

### Q: 我需要知道如何编码吗？
**A:** 不需要！这不是传统的编程仓库。你只需要知道如何使用 Issues 和编辑 markdown 文件。

### Q: 什么是 Markdown？
**A:** Markdown 是一种简单的格式化语言。我们用它来写漂亮的文档。# 表示标题，* 创建列表等。

### Q: 我如何进行"提交"？
**A:** GitHub 自动跟踪你所做的更改。当你编辑文件时，GitHub 要求你留下一条消息（提交消息），解释你改了什么。

### Q: 我可以撤销更改吗？
**A:** 是的！GitHub 记录所有更改。你可以查看历史并恢复旧版本。

2. 点击"添加合作者"
3. 输入他们的 GitHub 用户名
4. 他们将收到邀请
