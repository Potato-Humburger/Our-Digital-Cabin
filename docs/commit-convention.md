# 💻 Gitmoji 提交指南

我们使用 **Gitmoji** 来让我们的提交历史更有趣、更有意义。

## 📚 完整的 Gitmoji 列表

### 💝 回忆与里程碑
- `💝` 添加回忆、照片或里程碑
- `🎉` 庆祝特殊日期或事件
- `📸` 上传照片或视觉内容

### 📝 文档与记录
- `📝` 更新文档、日记或计划
- `📄` 添加新的文件或笔记
- `📋` 更新清单或待办事项

### 💕 关系与表达
- `💌` 添加情书或深层感情表达
- `💬` 更新对话、讨论或状态
- `❤️` 特殊的爱情表达

### 🎯 计划与组织
- `📅` 添加日期、计划或时间表
- `🎯` 制定新目标或计划
- `✏️` 编辑和改进计划

### ✨ 特殊功能
- `✨` 添加新功能或改进
- `🚀` 启动新项目或功能
- `🎬` 创建观影清单或娱乐相关

### 🐛 问题与修复
- `🐛` 修复错误或问题
- `🔧` 更新配置或设置
- `🗑️` 删除不需要的文件

### 🌟 其他
- `💬` 一般消息或更新
- `🔐` 隐私或安全相关
- `🎁` 特殊礼物或惊喜计划

---

## 📝 提交示例

```
💝 添加 2026-08-20 周年纪念照片

📸 上传海滩旅行的美好回忆

📝 更新周末约会计划

💌 写给你的情书 #1

📅 添加 9 月旅行日期

🐛 修复回忆时间线排序问题

✨ 创建观影清单追踪系统

💬 今日心情更新

🎉 庆祝三个月纪念日！
```

---

## 🎯 使用规则

1. 在提交消息的开头使用表情符号
2. 在表情符号后添加空格
3. 用简洁、有意义的语言描述您的更改
4. 用中文或英文都可以
5. 尽可能具体

---

## 💡 最佳实践

- **保持简洁**: 提交消息应该是简短的
- **描述性强**: 别人应该能从消息中理解你做了什么
- **情感丰富**: 这是我们的特殊空间，让情感反映在消息中！
- **使用中文**: 虽然英文也可以，但中文会让它更个人化
