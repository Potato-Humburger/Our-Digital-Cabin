# 🎬 观影清单

我们想看的电影、电视剧和综艺节目的追踪系统。

## 📺 分类

### 🎥 电影
我们想看或已经看过的电影。

### 📺 电视剧
我们一起追剧的节目。

### 🎪 综艺
特别的演出和综艺节目。

---

## 📊 数据格式

查看 [movies.json](./movies.json) 了解数据结构。

每一项包括：
- **标题** - 电影/节目的名字
- **类型** - 喜剧、戏剧、动作等
- **年份** - 发布年份
- **评分** - 我们给它的评分（1-5 星）
- **状态** - 已看 / 想看 / 观看中
- **笔记** - 我们的想法

---

## 🎯 如何添加新标题

1. 编辑 [movies.json](./movies.json)
2. 添加一个新的条目到数组中
3. 提交并推送

示例：
```json
{
  "title": "The Notebook",
  "type": "爱情戏剧",
  "year": 2004,
  "rating": 5,
  "status": "watched",
  "watched_date": "2026-08-15",
  "notes": "非常浪漫和感人💕"
}
```
