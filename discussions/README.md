## 💡 如何开始讨论

1. 前往 [讨论标签](https://github.com/Potato-Humburger/Our-Digital-Cabin/discussions)
2. 点击"新建讨论"
3. 选择相关的类别
4. 输入标题和信息
5. 发布！

---

## 🤝 讨论规则

- 尊重彼此的观点
- 保持讨论相关
- 享受对话！
- 回复对方的评论
