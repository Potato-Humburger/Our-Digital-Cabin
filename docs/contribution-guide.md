# 📚 贡献指南

欢迎！这是一个关于如何为我们的数字小屋做贡献的指南。

## 🏠 这是什么地方？

这个仓库是我们作为情侣分享回忆、梦想、计划和日常想法的一个特殊空间。这不是一个传统的代码仓库——这是我们爱的见证。

## 🎯 如何参与

### 1. 分享每日想法
- 前往 **[Issues](https://github.com/Potato-Humburger/Our-Digital-Cabin/issues)**
- 点击 **"新建 Issue"**
- 选择 **"💭 每日想法"** 模板
- 分享你今天的想法、感受和有趣发现

### 2. 写情书
- 前往 **Issues → 新建**
- 选择 **"💌 情书"** 模板
- 用你的方式表达爱
- 发送给你的爱人 💕

### 3. 计划约会
- 使用 **"🎯 约会想法"** 模板
- 建议地点、时间和活动
- 讨论预算和特殊元素
- 标记完成后的约会为 `🎉-完成`

### 4. 分享回忆
- 选择 **"📸 回忆"** 模板
- 添加照片或故事
- 描述为什么这个时刻特别
- 分享永恒的话语

## 💬 使用讨论

除了 Issues，我们也可以使用 **[GitHub Discussions](https://github.com/Potato-Humburger/Our-Digital-Cabin/discussions)**：

- **📸 Photos & Updates** - 分享照片和更新
- **🎬 Entertainment** - 讨论电影、剧集、游戏
- **✈️ Travel Talk** - 计划和讨论旅行
- **💑 Relationship** - 关系话题和检查
- **🌟 Dreams & Goals** - 长期计划和梦想
- **🎮 Games & Fun** - 玩游戏和有趣的事情
- **🗣️ General Chat** - 随意对话

## 📁 文件编辑

### 更新数据文件
编辑以下 JSON 文件来保持信息最新：

- **`data/metrics.json`** - 更新关系统计
- **`data/status.json`** - 更新当前心情和位置
- **`data/config.json`** - 自定义设置

### 更新文档
- **`dates/calendar.md`** - 添加重要日期
- **`dates/anniversaries.json`** - 更新纪念日列表
- **`dates/future-plans.md`** - 编辑共同梦想
- **`projects/watchlist/`** - 管理观影清单
- **`memories/timeline.md`** - 整理时间轴

## 🎨 提交信息

请遵循我们的 [Gitmoji 指南](./commit-convention.md)：

```
💝 添加 2026-08-20 周年纪念照
📸 上传海滩旅行照
📝 更新周末约会计划
💌 情书 #1
🐛 修复回忆时间排序
```

## 🔒 隐私提醒

- 这个仓库是**私密的**
- 只有你们两个可以看到
- 不要在提交中包含真实地址或敏感个人信息
- 使用 `.gitignore` 来保护敏感文件

## 📋 标签指南

使用这些标签来组织 Issues：

- **💚-心对心** - 重要的个人信息
- **📸-回忆** - 回忆和照片
- **🎯-约会** - 约会计划
- **💌-情书** - 情书和深层情感
- **📝-想法** - 每日想法
- **🎉-庆祝** - 特殊日期庆祝
- **💭-计划** - 计划和想法
- **💭-语录** - 爱情语录和引言

## 🚀 工作流启用

工作流已设置但默认禁用。要启用：

1. 前往 **Settings → Actions → General**
2. 确保 Actions 已启用
3. 工作流将自动运行
