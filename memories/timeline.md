这是我们共同旅程的时间轴。所有珍贵的回忆和里程碑都在这里组织。

```

│   ├── 03-march/

│   ├── 11-november/
│   └── 12-december/
├── 2027/
│   └── ...
└── milestones.json       # 特殊里程碑
```

## 🎯 如何添加回忆

### 添加照片
1. 进入相应的月份文件夹（例如 `memories/2026/08-august/`）
2. 在 GitHub 中上传照片或在 Issue 中包含照片

### 写故事
在相应月份创建 markdown 文件：
```
memories/2026/08-august/beach-day.md
```

### 使用 Issues
每个回忆都可以作为一个 Issue 创建，使用"📸 回忆"模板。
